Complete 6-Month Intensive Curriculum Roadmap

Phase 1: AI-Powered Business Automation (Weeks 1-4)
Week 1 Google Workspace & Sheets Foundation
  • Workspace Intro: Navigating Google Workspace and setting up cloud databases.
  • Mathematical Operations: Core syntax for addition, subtraction, multiplication, and division.
  • Data Lookups: Deep dive into VLOOKUP, modern XLOOKUP, and INDEX/MATCH combinations.
  • Pre-Defined Master Sheet: Students receive a fully pre-configured Google Sheet containing all formulas, formatted tables, and sample data to use as a live reference tool.
Week 2 AppSheet & Low-Code Architecture
  • Interface Configuration: Connecting the Google Sheet backend, creating Views, and assigning User Roles.
  • Master App 1 (Inventory): Building an end-to-end stock control application with barcode scanning and automated deductions.
  • Master App 2 (HR App): Developing a leave-approval portal emphasizing Row-Level Security (RLS) to ensure employees only see their own data, plus dynamic supervisor views.
Week 3 Google Apps Script & Autonomous Agents
  • Scripting Fundamentals: Editor navigation, JavaScript syntax basics, and writing custom functions.
  • Event-Driven Triggers: Configuring onEdit, onChange, and onOpen triggers to execute code dynamically on sheet interactions.
  • Scheduled Automations: Setting up time-driven triggers to run scripts at specific intervals.
  • Email Agent Architecture: Understanding the distinct limits and use-cases of GmailApp vs. MailApp. Building autonomous background agents that execute jobs based on set conditions.
Week 4 Integration & Phase Conclusion
  • AppSheet Automations: Building bots and event actions directly within the AppSheet interface.
  • Platform Merging: Connecting Apps Script agents to AppSheet workflows.
  • Deployment: Finalizing the HR and Inventory apps and applying security protocols.
Phase 2: n8n Workflow Automation (Weeks 5-6)
Week 5 n8n Zero to One
  • Core Concepts: Understanding node-based visual workflow engines, Triggers, and JSON data flow.
  • First Workflows: Connecting Google Sheets triggers to automated Slack/Discord messaging.
Week 6 Advanced Logic & APIs
  • Webhooks & APIs: Mastering the HTTP Request Node to connect n8n to custom web tools.
  • AI Agents: Integrating OpenAI nodes to intelligently route, analyze, and process incoming business data.
Phase 3: Robotic Process Automation (Weeks 7-8)
Week 7 Power Automate Desktop Basics
  • Desktop Automation Intro: Navigating the UI, creating desktop flows, and utilizing the desktop recorder.
  • Variable Management: Setting inputs, outputs, and manipulating variables for repetitive tasks.
Week 8 Advanced RPA Workflows
  • Web & Excel Scraping: Automating data extraction from live websites and manipulating local Excel files without human input.
  • Error Handling: Building resilient UI flows with block errors and sub-flows.
Phase 4: Next-Gen Data Analytics (Weeks 9-12)
Week 9 Data Ingestion & Power Query
  • ETL Fundamentals: Extract, Transform, Load processes using Power Query Editor.
  • Data Cleaning: Profiling, shaping, unpivoting columns, and merging dirty datasets into usable formats.
Week 10 Data Modeling & DAX
  • Star Schema: Establishing active/inactive relationships and building Fact vs. Dimension tables.
  • Mastering DAX: Execution contexts, CALCULATE, time intelligence (YTD, MTD), and iterative functions.
Week 11 Visualizations & UX
  • Visual Selection: Choosing the right charts (Matrix, Scatter, Line) for the data story.
  • Interactivity: Configuring Slicers, drill-downs, cross-filtering, and custom tooltips.
Week 12 Publishing & Administration
  • Power BI Service: Uploading reports, managing workspaces, and configuring scheduled dataset refreshes.
  • Phase 4 Wrap-Up: Building a complete executive dashboard from scratch.
Phase 5: Live Internship & Career Acceleration (Months 4-6)
Months 4-5 Live Project Building & Mentorship
  • Integrated Corporate Projects: Building comprehensive solutions using AppSheet, Apps Script, n8n, Power Automate, and Power BI simultaneously.
  • Live Assignments: Weekly tasks mimicking real-world UK business requirements.
  • 1-on-1 Mentorship: Dedicated doubt-solving sessions, live code reviews, and architecture feedback.
Month 6 Professional Branding & Placement Prep
  • Resume Building: Crafting ATS-friendly resumes highlighting automation and analytics portfolios.
  • Profile Configuration: Optimizing LinkedIn and Naukri profiles for maximum recruiter visibility.
  • Mock Interviews: Technical and HR interview simulations with industry experts.
  • Graduation: Final evaluation and issuance of the Course Completion and Internship Completion certificates.
